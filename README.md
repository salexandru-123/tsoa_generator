# Create TSOA Project

A cross-platform CLI for generating TypeScript projects using TSOA and Express.

## Requirements

- Node.js >= 18
- npm or pnpm

## Install globally

Using npm:
```
npm install -g @salexandru-123/tsoa_generator

```

Using pnpm:
```
pnpm install -g @salexandru-123/tsoa_generator
```

## Usage

Global installation:

```any terminal
tsoa_generate /path/to/project
```

Using npx:

```bash
npx tsoa_generate /path/to/project
```

Using pnpm:

```bash
pnpm dlx create-tsoa-project my-api
```

## Supported operating systems

- Windows
- Linux
- macOS

The CLI automatically detects the operating system and executes the appropriate installation script.

## Generated stack

- TypeScript
- TSOA
- Express
- Swagger UI
- Multer
- CORS
- pnpm
